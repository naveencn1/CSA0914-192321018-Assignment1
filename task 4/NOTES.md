# Task 4 – Classes, Objects and Constructors
ParkingTicket: parameterised constructor (validates, assigns unique number) and copy constructor (duplicate print of the same ticket). Vehicle: protected validating constructor; subclasses chain with `super(regNo)`; `this` used to separate fields from parameters.
Memory: reference variables on the stack, objects on the heap.
Alternative: default constructor + setters allows half-built objects; static factory validates like a constructor. Creating n tickets is O(n) time and space in all.
